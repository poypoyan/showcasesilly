# showcasesilly
Showcase my silly projects.

## Setup
1. Run `grabfiles.py`. On each project folder created, one HTML file will be renamed as `index.html`.
2. Craft your own `index.html` and `404.html`. The projects must be referenced in links (href) as `/project-folder/`.
3. Either run, or build and run the web server:
```bash
go run main.go
```
or
```bash
go build main.go
./main
```
